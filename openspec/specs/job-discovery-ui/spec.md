# Spec: Job Discovery UI

## ADDED Requirements

### Requirement: 扫描配置

用户可以管理职位扫描的来源和关键词。

#### Scenario: 查看扫描源

- **WHEN** 用户打开职位发现页面
- **THEN** 显示已配置的公司扫描源列表（来自 portals.yml）
- **AND** 每个源显示公司名、平台类型、状态

#### Scenario: 编辑关键词

- **WHEN** 用户编辑搜索关键词
- **THEN** 可以添加/删除正向关键词（匹配的岗位类型）
- **AND** 可以添加/删除负向关键词（排除的岗位）
- **AND** 修改后自动保存到配置

### Requirement: 扫描结果浏览

用户可以查看扫描发现的新职位。

#### Scenario: 新职位列表

- **WHEN** 扫描完成后
- **THEN** 以卡片形式展示新发现的职位
- **AND** 每张卡片显示：公司、岗位、平台、发现时间、快速操作（评估/跳过）

#### Scenario: 职位详情预览

- **WHEN** 用户点击某个新职位
- **THEN** 展开显示 JD 摘要和关键信息
- **AND** 提供"一键评估"按钮直接进入评估流程

#### Scenario: 已处理/已跳过

- **WHEN** 用户标记职位为"已跳过"或完成评估
- **THEN** 该职位从新职位列表中移除
- **AND** 跳过的职位记录在历史中，可恢复

### Requirement: 扫描触发

用户可以手动或定时触发扫描。

#### Scenario: 手动扫描

- **WHEN** 用户点击"扫描新职位"
- **THEN** 显示扫描进度（当前扫描的公司）
- **AND** 完成后显示新发现职位数量

#### Scenario: 扫描历史

- **WHEN** 用户查看扫描历史
- **THEN** 显示历次扫描的时间、发现数量、新增数量
