# Spec: Application Tracker UI

## ADDED Requirements

### Requirement: 投递列表视图

用户可以在一个清晰的列表中查看所有投递记录，支持多种视图模式和排序方式。

#### Scenario: 默认列表视图

- **WHEN** 用户打开投递追踪页面
- **THEN** 以列表形式显示所有投递记录
- **AND** 每条记录显示：序号、公司、岗位、评分、状态、日期、操作
- **AND** 记录按日期倒序排列

#### Scenario: 状态分组视图

- **WHEN** 用户切换到分组视图
- **THEN** 投递记录按 8 种规范状态分组显示
- **AND** 每个分组显示应用数量和占比
- **AND** 分组以温暖的色彩编码区分

#### Scenario: 看板视图

- **WHEN** 用户切换到看板视图
- **THEN** 投递记录以 Kanban 列显示（每列一个状态）
- **AND** 可以通过拖拽改变投递状态

### Requirement: 状态管理

用户可以更新任意投递记录的状态，状态变更记录时间。

#### Scenario: 状态更新

- **WHEN** 用户点击某条投递的状态标签
- **THEN** 弹出 8 种规范状态的选择器
- **AND** 选择新状态后即时更新
- **AND** 状态变更时间自动记录

#### Scenario: 面试进度追踪

- **WHEN** 用户将状态更新为"面试中"
- **THEN** 提示输入面试轮次和日期
- **AND** 在记录中显示面试进度（如"第2轮/共3轮"）

#### Scenario: Offer 记录

- **WHEN** 用户将状态更新为"已获 Offer"
- **THEN** 提示输入 Offer 关键信息（薪资、期权、入职时间）
- **AND** 自动创建 Offer 对比条目

### Requirement: 搜索与过滤

用户可以快速找到特定的投递记录。

#### Scenario: 关键词搜索

- **WHEN** 用户在搜索框中输入公司名或岗位名
- **THEN** 实时过滤显示匹配的记录
- **AND** 搜索结果高亮匹配文字

#### Scenario: 多条件过滤

- **WHEN** 用户使用过滤器
- **THEN** 可以按状态、评分范围、日期范围、岗位类型组合过滤
- **AND** 过滤条件以温和的标签形式显示，可随时移除

### Requirement: 批量操作

用户可以对选中的多条记录执行批量操作。

#### Scenario: 批量状态更新

- **WHEN** 用户勾选多条记录并选择新状态
- **THEN** 所有选中记录的状态同时更新
- **AND** 操作可撤销

#### Scenario: 批量导出

- **WHEN** 用户选中多条记录并点击导出
- **THEN** 导出为 applications.md 兼容的 Markdown 表格
- **AND** 可直接粘贴回 CLI 系统的 data/applications.md
