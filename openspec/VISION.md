# 筝筝纸鸢 — AI 求职助手 产品迭代蓝图

> 从「AI 辅助工具」进化为「自主求职智能体」

## 现状诊断

| 维度 | 当前状态 | 问题 |
|------|---------|------|
| AI 深度 | explore 页聊天 + summarize | 其他 8 个页面几乎无 AI |
| 数据流 | localStorage + IndexedDB | 数据孤立，无关联学习 |
| 自动化 | 0（全手动操作） | 用户要做所有事 |
| 面试 | 硬编码题目 + 手动 STAR | 无个性化、无反馈 |
| 简历 | 静态管理 + 基础版 PDF | 无 JD 定向优化 |
| 职位发现 | CLI 爬虫（国内不可用） | 功能基本失效 |
| 差异化 | "手帐"概念 + 本地存储 | 概念好但功能太浅 |

当前 API 路由（12个）：chat/stream, chat/summarize, cv/analyze, cv/optimize-section, cv, evaluate, interview/questions, fetch-jd, scan/status, data/import, generate-cv-pdf, ocr/jd-screenshot

# V1.5 — AI 深度融入（预计 4-6 周）

> 目标：每个现有页面都有 AI 能力。用户感觉到 AI 在"帮"他，而不是只能"问"AI。

## 1.5.1 JD 智能评估引擎（2周）

### 功能
- **粘贴即评**：URL / 截图 / 纯文本 → 流式输出结构化评估报告
- **语义匹配**：JD 关键要求 × 用户简历 → 匹配度打分 + 差距分析
- **隐藏信息解读**：训练 LLM 识别 JD 中的"行话暗语"
  - "快速迭代" → 可能加班频繁
  - "扁平化管理" → 晋升路径不清晰
  - "抗压能力强" → 工作强度大
  - "独角兽潜力" → 风险较高
- **五维雷达图**：技能匹配 / 经验匹配 / 薪资匹配 / 成长空间 / 风险指数
- **一句话建议**："这个岗位值得投，但面试时要问清楚汇报线和团队规模"

### API
- `POST /api/evaluate/jd` — 流式输出评估报告
- `POST /api/evaluate/score` — 匹配度打分（非流式）

### 前端
- 评估结果页改版：雷达图 + 分段分析 + 行动建议
- evaluate/jds 页面增加"快速评估"入口（粘贴框）
- 评估历史可搜索、可对比

## 1.5.2 简历 AI 引擎（1.5周）

### 功能
- **JD 定向优化**：选目标 JD → AI 重写简历 → 保持真实，优化关键词密度
- **量化提取**：从用户的聊天记录/经历描述中，AI 自动提取可量化的成果
  - "我负责了用户增长" → "主导用户增长策略，DAU 从 X 提升到 Y (+Z%)"
- **ATS 兼容检查**：评估简历通过机器筛选的概率
  - 关键词密度、格式兼容性、段落结构评分
- **多版本管理**：支持"AI产品经理版"、"AI运营版"、"通用版"并行维护
- **简历评分**：对每份简历给出综合评分 + 改进建议

### API
- `POST /api/cv/tailor` — 根据 JD 定制简历
- `POST /api/cv/score` — 简历评分 + ATS 兼容检查
- `POST /api/cv/quantify` — 量化经历提取

### 前端
- cv 页面增加「定向优化」面板
- 简历版本列表 → 每份显示评分 + 适用方向
- 优化对比视图：原版 vs AI优化版 左右对照

## 1.5.3 面试 AI 教练 V1（1.5周）

### 功能
- **动态出题**：根据 JD + 用户简历 + 弱项，生成面试题目
  - 不再是 hardcode 题库，每份 JD 都能生成专属问题
  - 题型：行为面试 / 技术专业 / 案例分析 / 文化匹配
- **面试回答教练**（六种模式覆盖国内全场景）：
  - **模式1: 项目复盘** — 互联网大厂/科技公司（60%场景）
    - 结构：背景→角色→难点→思考过程→方案→结果→反思→数据
    - 字节追数据、腾讯追产品感、阿里追价值观
  - **模式2: 行为问答** — 外企/咨询（15%场景）
    - 结构：Situation→Task→Action→Result→Reflection
  - **模式3: 情景应对** — 大厂交叉面/群面/管培（15%场景）
    - 结构：理解问题→拆解分析→方案→风险→反问
  - **模式4: 结构化面试** — 中小企业 50-500 人（高频场景）
    - 结构：「为什么来」→「做过什么」→「怎么做的」→「结果」→「能带来什么」
    - HR 懂业务、追细节、看重稳定性和即战力
  - **模式5: 创始人对话** — 初创/微型 <50 人
    - 结构：「你理解我们在做什么吗」→「你能立刻上手做什么」→「薪资期望」→「能接受创业节奏吗」
    - 重点：展示多面手能力 + 识别风险信号（口头承诺、社保、期权真实性）
  - **模式6: 稳重应答** — 国企/央企/银行
    - 不看框架看"味道"：学历背景→政治觉悟→服从意识→长期规划→家庭情况
- **回答评分**：用户输入自己的回答 → AI 打分 + 改进建议
  - 维度：结构完整度 / 具体程度 / 亮点突出 / 时间控制
  - 各模式评分权重不同（如国企模式弱化"亮点突出"、强化"稳重得体"）

### API
- `POST /api/interview/generate` — 基于 JD+简历生成题目（替代现有硬编码 route）
- `POST /api/interview/coach` — 回答教练（输入经历 + 选择模式 → 结构化回答 + 追问）
- `POST /api/interview/score` — 回答评分 + 改进建议

### 前端
- interview 页面大改版：三个 Tab（出题 / 教练 / 题库）
- 教练 Tab：左侧输入经历 + 选择面试模式（六选一），右侧实时生成结构化回答
- 题目卡片式展示，可展开看答案提示
- 大厂/公司类型预设联动出题和教练模式

## 1.5.4 数据分析 AI 洞察（1周）

### 功能
- **AI 周报**：每周自动生成求职健康报告
  - "本周投递 5 份，通过率 40%，高于平均水平"
  - "你的 AI PM 方向通过率最高(60%)，建议重点投递"
- **异常检测**：
  - 某公司回复速度异常快 → 可能是急招/流动性高
  - 某方向投递很多但零回复 → 简历或方向有问题
- **Pipeline 健康度**：
  - "你的 Pipeline 呈漏斗状健康分布"
  - "警告：80% 申请在初筛阶段，缺少后期机会 → 建议暂停新投递，集中跟进"
- **预测引擎**：
  - 基于当前进度和转化率，预测收到 Offer 的时间窗口
  - "按当前进度，预计 3-4 周内会有第一个 Offer"

### API
- `POST /api/analytics/weekly-report` — 生成 AI 周报
- `POST /api/analytics/health-check` — Pipeline 健康检查

### 前端
- analytics 页面增加「AI 洞察」卡片
- 首页"今日手帳"展示每日 AI 摘要
- Pipeline 健康指示灯（绿/黄/红）

## 2.0.1 动态求职画像 — Career DNA（2周）

### 概念
一份**持续自我进化**的个人档案。每次对话、每次评估、每次面试反馈都在更新它。

### 功能
- **自动学习**：
  - 从 explore 聊天中提取：偏好、价值观、职业锚点
  - 从 JD 评估中学习：什么类型的岗位你更感兴趣/更匹配
  - 从面试反馈中学习：你的强项和弱项
- **技能市场分析**：
  - 抓取行业趋势数据 → "大模型应用落地"需求暴涨 300%
  - 对比你的技能栈 → "你缺少 X，但市场正在为此付溢价"
- **差距分析**：
  - 目标岗位 vs 你的画像 → 精确到技能维度的差距清单
  - 每个差距附带学习资源推荐
- **路径模拟器**：
  - "如果接下 A 岗位 → 3 年后可能成为 B 或 C"
  - "如果先做 D 1 年再转 E → 预期薪资增长 F%"
- **可见的成长**：
  - 画像变化时间线：1 个月前 vs 现在
  - "你的竞争力分数从 72 提升到 81"

### 数据模型
```typescript
interface CareerDNA {
  // 基础
  skills: SkillWithProficiency[];        // 技能 × 熟练度
  archetypes: string[];                  // 适合的职业原型
  
  // 偏好（从对话中学习）
  preferences: {
    companySize: PreferenceVector;       // 偏好度分数 0-1
    industry: Record<string, number>;
    culture: Record<string, number>;
    workStyle: Record<string, number>;
  };
  
  // 市场对标
  marketFit: {
    score: number;                       // 综合竞争力 0-100
    trendingSkills: SkillGap[];          // 市场需求但你不具备的技能
    salaryRange: { min: number; max: number };
  };
  
  // 进化历史
  history: DNAVersion[];                 // 每次更新的快照
}
```

### 前端
- 新的独立页面或首页核心模块
- 雷达图 + 时间线 + 差距列表
- "DNA 进化史"时间轴动画

## 2.0.2 自主求职 Agent V1（2.5周）

### 概念
用户设定目标和偏好 → Agent 7×24 运作 → 用户只做审批

### 功能
- **目标设定向导**（交互式 Agent）：
  1. "你想找什么样的工作？"（角色、级别）
  2. "薪资底线是多少？理想薪资呢？"
  3. "哪些条件是绝对不能妥协的？"（不加班、不出差、不外包...）
  4. "你对公司有什么偏好吗？"（规模、行业、文化）
  5. Agent 总结目标 → 用户确认 → 开始运作

- **每日运作**：
  - 扫描用户粘贴的 JD → 自动评估 → 排序
  - 每天早上推送：「今日 Top 3 匹配岗位」
  - 每个推荐附带：匹配度 + 关键理由 + 风险提示 + 建议行动

- **定制材料**：
  - 对高匹配岗位 → 自动生成定制简历 + 求职信
  - 用户审核（可在手机上快速浏览）

- **Pipeline 自动管理**：
  - 新 JD 自动入库 → 评估 → 排序
  - 过期 JD 自动归档
  - 跟进提醒：「你 5 天前面了 XX 公司，该跟进了」

### 前端
- 首页「今日手帳」大改版：Agent 仪表盘
- 目标设定界面（分步向导，温暖的手帐风格）
- 每日摘要卡片：「今早 Agent 为你找到 3 个好机会」
- 审批流：快速浏览 → 左滑跳过 / 右滑保存

# V2.5 — 多智能体架构（预计 8-10 周）

> 目标：从"一个 AI"变成"一组 AI 专家团队"。这是实现 Level 3 自主运作的架构基础。

## 2.5.1 Multi-Agent 架构（3周）

### 架构设计

```
┌─────────────────────────────────────────────────────────┐
│                    Orchestrator Agent                    │
│              "用户意图 → 任务分解 → 调度执行"               │
└────┬────────┬────────┬────────┬────────┬────────┬───────┘
     │        │        │        │        │        │
┌────▼──┐ ┌──▼───┐ ┌──▼───┐ ┌──▼───┐ ┌──▼───┐ ┌──▼────┐
│Search │ │Eval  │ │Resume│ │Interview│ │Negot-│ │Track  │
│Agent  │ │Agent │ │Agent │ │Agent   │ │iation│ │Agent  │
│       │ │      │ │      │ │        │ │Agent │ │       │
│多源搜索│ │深度评估│ │简历定制│ │出题+教练│ │薪酬分析│ │状态追踪│
│去重过滤│ │风险识别│ │关键词优│ │STAR生成│ │话术生成│ │跟进提醒│
│趋势发现│ │匹配理由│ │版本管理│ │表现分析│ │合同审查│ │流失预警│
└───────┘ └──────┘ └──────┘ └────────┘ └───────┘ └───────┘
     │        │        │        │        │        │
     └────────┴────────┴───┬────┴────────┴────────┘
                           │
                    ┌──────▼──────┐
                    │  Shared      │
                    │  Memory      │
                    │  (Career DNA) │
                    └─────────────┘
```

### 技术方案
- **Orchestrator**：主控 Agent，理解用户意图，分解任务
- **专用 Agent**：每种 Agent 有独立的 system prompt + tool set
- **共享记忆**：Career DNA 作为所有 Agent 的上下文基础
- **通信协议**：Agent 之间通过结构化消息传递结果

### 框架选择

| 选项 | 优势 | 劣势 |
|------|------|------|
| **直接调用 LLM + 自建编排** | 零依赖、完全可控 | 需自己实现状态管理 |
| **LangGraph** | 状态图、人机协同节点 | 学习曲线、较重 |
| **Vercel AI SDK** | 与 Next.js 深度集成 | Agent 能力较基础 |

**建议**：V2.5 初期用 Vercel AI SDK + 自建编排逻辑，避免过早引入重型框架。

### API
- `POST /api/agent/orchestrate` — 主控入口
- `POST /api/agent/{agent-name}/execute` — 各 Agent 执行接口

## 2.5.3 谈判助手（1.5周）

### 功能
- **薪酬对标**：
  - 同公司/同行业/同级别的真实薪酬范围

- **话术生成**：

- **合同审查**：
  - 上传 Offer 合同 → AI 识别关键条款
  - 竞业限制范围分析："这个条款会封锁你进入 80% 的目标公司"

### API

- `POST /api/negotiate/script` — 谈判话术生成

  - 输入税前月薪 + 城市 → 精确计算税后收入
  - 对比不同城市/公司的实际到手
  - 公积金基数、缴纳比例差异对比
- **公司分类评价**：
  - 国企/私企/外企/创业公司 — 不同维度的评价权重
  - 国企：编制/户口/稳定性
  - 私企：现金流/业务健康度/加班文化
  - 外企：全球化程度/中国区话语权/裁员历史
- **竞业限制风险库**：
  - 已知有严格竞业的公司列表
  - 竞业范围分析：签署后会被限制进入哪些公司
- **落户/签证支持**：
  - 一线城市落户政策对比

# 关键风险

| 风险 | 影响 | 缓解 |
|------|------|------|
| LLM API 成本过高 | V2.0+ Agent 频繁调用 | 缓存 + 分级模型（小模型做简单任务） |
| 国内平台反爬 | 公司情报/职位发现 | 以用户主动粘贴为主，不做被动爬取 |
| 个人信息保护法 | 用户数据处理 | 坚持本地存储 + PII 脱敏（已是优势） |
| 功能膨胀 | 开发周期失控 | 每版本严格 MVP，砍非核心功能 |
