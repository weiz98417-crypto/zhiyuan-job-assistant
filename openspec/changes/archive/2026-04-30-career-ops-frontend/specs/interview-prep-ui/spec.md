# Spec: Interview Prep UI

## ADDED Requirements

### Requirement: STAR+R 故事库

用户可以积累和管理面试用的 STAR+R 故事。

#### Scenario: 查看故事库

- **WHEN** 用户打开故事库
- **THEN** 以卡片形式展示所有 STAR+R 故事
- **AND** 每个故事显示标题、来源、适用问题标签

#### Scenario: 添加新故事

- **WHEN** 用户点击"添加故事"
- **THEN** 显示 STAR+R 表单：情境(S)、任务(T)、行动(A)、结果(R)、反思(Reflection)
- **AND** 支持添加"适用于什么问题"的标签

#### Scenario: 按问题筛选故事

- **WHEN** 用户在搜索框中输入问题（如"你最大的失败是什么"）
- **THEN** 系统匹配并推荐最相关的 STAR+R 故事
- **AND** 显示匹配理由

### Requirement: 公司研究

用户可以为目标公司准备面试研究资料。

#### Scenario: 创建公司研究

- **WHEN** 用户输入公司名并点击"研究"
- **THEN** 系统生成公司研究模板：业务模式、融资情况、团队规模、技术栈、竞品、面试流程
- **AND** 关联该公司的所有投递记录和评估报告

#### Scenario: 面试问题生成

- **WHEN** 用户查看公司研究页面
- **THEN** 系统基于 JD 和公司信息生成可能的面试问题
- **AND** 问题按类别分组：行为面试、技术/专业、案例分析、文化匹配

### Requirement: 面试日程

用户可以追踪面试安排和准备进度。

#### Scenario: 面试日程视图

- **WHEN** 用户有待进行的面试
- **THEN** 在首页和面试准备页显示即将到来的面试
- **AND** 以时间线形式展示：公司、岗位、轮次、日期、准备状态

#### Scenario: 面试准备清单

- **WHEN** 用户点击某场面试
- **THEN** 显示准备清单：研究公司、复习 JD、准备故事、准备反问、技术复习
- **AND** 每项可勾选完成
