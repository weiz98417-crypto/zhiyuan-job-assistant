# Spec: Analytics UI

## ADDED Requirements

### Requirement: 转化漏斗

用户可以查看求职全流程的转化数据。

#### Scenario: 漏斗图

- **WHEN** 用户打开数据分析页面
- **THEN** 显示转化漏斗：已评估 → 已投递 → 已回复 → 面试中 → 已获 Offer
- **AND** 每层显示数量和转化率
- **AND** 漏斗以温暖的渐变色渲染（非标准蓝色漏斗）

#### Scenario: 时间段对比

- **WHEN** 用户选择时间段对比（如本月 vs 上月）
- **THEN** 并排显示两个时间段的漏斗
- **AND** 标注变化趋势（↑↓ 箭头）

### Requirement: 拒绝模式分析

系统自动分析被拒原因并提供改进建议。

#### Scenario: 拒绝原因分类

- **WHEN** 用户查看拒绝分析
- **THEN** 拒信按原因分类：技能不匹配、薪资期望过高、经验不足、位置限制、竞业限制
- **AND** 以比例图展示各类占比

#### Scenario: 改进建议

- **WHEN** 系统检测到模式（如"连续3次因同一技能被拒"）
- **THEN** 生成具体的改进建议
- **AND** 建议关联到简历优化或面试准备的行动项

### Requirement: 跟进提醒

系统根据投递时间自动计算需要跟进的投递。

#### Scenario: 跟进列表

- **WHEN** 用户打开跟进提醒
- **THEN** 显示需要跟进的投递列表，按紧急程度排序
- **AND** 每项显示：公司、岗位、投递日期、已过天数、建议跟进方式

#### Scenario: 跟进频率规则

- **WHEN** 投递已超过 7 天未回复
- **THEN** 标记为"待跟进"
- **AND** 超过 14 天标记为"需关注"
- **AND** 超过 30 天标记为"可能已凉"

### Requirement: 求职周报

系统自动生成每周求职摘要。

#### Scenario: 周报内容

- **WHEN** 用户在首页查看本周摘要
- **THEN** 显示：本周新投递数、本周面试数、本周 Offer 数、转化率变化
- **AND** 配上一句温暖的鼓励语（如"本周你的匹配度比上周提升了15%，策略调整在起效"）

#### Scenario: 历史趋势

- **WHEN** 用户查看趋势图
- **THEN** 显示近 8 周的投递数、面试数、Offer 数的折线图
- **AND** 标注关键事件（如"修改简历定位"）对趋势的影响
