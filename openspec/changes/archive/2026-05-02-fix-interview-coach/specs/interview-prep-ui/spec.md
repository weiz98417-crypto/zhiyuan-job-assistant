## MODIFIED Requirements

### Requirement: 面试问题生成

用户可以为目标岗位动态生成个性化面试题目，系统基于 JD 和简历内容生成针对性问题。

#### Scenario: 查看故事库

- **WHEN** 用户打开故事库
- **THEN** 以卡片形式展示所有 STAR+R 故事
- **AND** 每个故事显示标题、来源、适用问题标签

#### Scenario: 添加新故事

- **WHEN** 用户点击"添加故事"
- **THEN** 显示 STAR+R 表单：情境(S)、任务(T)、行动(A)、结果(R)、反思(Reflection)
- **AND** 支持添加"适用于什么问题"的标签

#### Scenario: 按问题筛选故事

- **WHEN** 用户在搜索框中输入问题（如"你最大的失败是什么"）
- **THEN** 系统匹配并推荐最相关的 STAR+R 故事
- **AND** 显示匹配理由

#### Scenario: 面试问题生成

- **WHEN** 用户选中 JD 库中的某个 JD 并点击"生成面试题目"
- **THEN** 系统读取该 JD 的完整正文和公司/职位信息
- **AND** 读取简历全文
- **AND** 调用 `/api/interview/generate` 传递 `jdText`、`cvText`、`company`、`role`
- **AND** 生成的题目基于 JD 实际内容和简历匹配度，而非通用题目

#### Scenario: 通用出题模式

- **WHEN** 用户未选择 JD（选择"通用出题"）
- **THEN** 系统仅传递公司预设风格和简历全文
- **AND** API 回退到通用出题策略
- **AND** 题目注明来源为 `general`

#### Scenario: CV 数据就绪状态

- **WHEN** 用户打开出题 Tab
- **THEN** 如果简历不为空，显示"简历已就绪"标签
- **AND** 如果简历为空，显示"未找到简历，将通用出题"标签
- **AND** 标签引导用户前往简历页补充

## ADDED Requirements

### Requirement: 教练多轮对话 UI

教练 Tab SHALL 以对话形式展示交互，支持多轮流式对话。

#### Scenario: 教练对话界面

- **WHEN** 用户进入教练 Tab
- **THEN** 显示模式选择器（六种模式）
- **AND** 显示对话区域，初始为空（无消息时显示引导文案）
- **AND** 底部固定输入框和发送按钮

#### Scenario: 流式回答渲染

- **WHEN** 教练 API 返回流式章节数据
- **THEN** 对话区域实时追加格式化的结构化回答
- **AND** 每个章节带有标题标签和内容文本
- **AND** 加载中显示思考动画，完成后隐藏

#### Scenario: 追问交互

- **WHEN** 助手回答流式完成后
- **THEN** 消息下方渲染追问建议按钮列表
- **WHEN** 用户点击追问按钮
- **THEN** 该追问作为用户消息发送
- **AND** 自动触发下一轮流式对话

#### Scenario: 手动继续对话

- **WHEN** 用户在输入框输入新内容并发送
- **THEN** 消息追加到对话历史
- **AND** 触发新一轮流式教练对话
- **AND** 上下文保持连贯（历史消息全部传递）

#### Scenario: 模式切换提示

- **WHEN** 对话中有历史消息时用户切换模式
- **THEN** 清空对话历史
- **AND** 显示"已切换到 X 模式，对话历史已清空"提示
