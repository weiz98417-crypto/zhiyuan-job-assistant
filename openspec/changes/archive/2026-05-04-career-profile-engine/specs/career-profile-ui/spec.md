## ADDED Requirements

### Requirement: 求职画像页面

系统 SHALL 提供 `/profile` 页面，以可视化方式展示用户的求职画像。

#### Scenario: 页面入口

- **WHEN** 用户点击导航中的"求职画像"
- **THEN** 跳转到 `/profile` 页面
- **AND** 页面以温暖的卡片布局展示画像的各维度

#### Scenario: 画像为空时的引导

- **WHEN** 用户首次访问画像页面且尚未生成画像
- **THEN** 显示引导卡片："你的求职画像尚未生成"
- **AND** 提供"开始分析"按钮，点击后调用 API 生成画像
- **AND** 说明："完成 3 次 JD 评估后，画像将更加准确"

#### Scenario: 画像生成中

- **WHEN** 用户点击"开始分析"后 API 计算中
- **THEN** 显示分析进度指示（"正在分析你的求职数据..."）
- **AND** 禁止重复点击

### Requirement: 技能雷达图

系统 SHALL 以 SVG 雷达图展示用户的技能分布。

#### Scenario: 雷达图渲染

- **WHEN** 画像包含技能数据
- **THEN** 以六边形或八边形雷达图展示各项技能及其熟练度
- **AND** 每个技能顶点标注技能名称和分数（0-100）
- **AND** 雷达图使用 Warm Amber 主色，半透明填充

#### Scenario: 无技能数据

- **WHEN** 画像中 skills 数组为空
- **THEN** 雷达图区域显示空状态："完成更多评估和练习来解锁技能分析"

### Requirement: 技能缺口清单

系统 SHALL 列表展示用户的目标岗位所需但尚未掌握的技能。

#### Scenario: 技能缺口展示

- **WHEN** 画像包含 skillGaps 数据
- **THEN** 以列表形式展示每项缺口技能
- **AND** 每项显示：技能名称、市场需求度（高/中/低）、当前水平、差距程度
- **AND** 按 gap 降序排列

#### Scenario: 无缺口数据

- **WHEN** 画像中 skillGaps 数组为空
- **THEN** 显示："暂未检测到明显技能缺口——继续探索更多岗位来发现成长方向"

### Requirement: 偏好分布展示

系统 SHALL 可视化用户的求职偏好（行业、公司规模、工作方式）。

#### Scenario: 偏好柱状图

- **WHEN** 画像包含 preferences 数据
- **THEN** 以水平柱状图展示各维度的偏好分布
- **AND** 公司规模维度显示 startup / sme / large 三段的偏好分数
- **AND** 行业维度显示 Top 5 行业的偏好分数
- **AND** 每个柱状条使用暖色渐变，分数越高越暖

### Requirement: 进化时间轴

系统 SHALL 展示画像的变更历史，让用户看到自己的成长轨迹。

#### Scenario: 时间轴渲染

- **WHEN** 画像的 history 数组包含多条记录
- **THEN** 以垂直时间轴展示每次画像变更
- **AND** 每条记录显示：时间、触发事件描述、具体变化内容
- **AND** 最新记录在顶部，使用 Warm Amber 强调色

#### Scenario: 竞争力分数变化

- **WHEN** history 中记录了多次竞争力分数变化
- **THEN** 时间轴旁显示迷你折线图，展示分数从首次到最新的变化趋势
