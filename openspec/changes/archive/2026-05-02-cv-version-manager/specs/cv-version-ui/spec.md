## ADDED Requirements

### Requirement: 版本选择器 UI

CV 页面顶部 SHALL 显示版本选择器，包含当前版本名称、下拉菜单和新建按钮。

#### Scenario: 版本选择器渲染

- **WHEN** 用户进入 CV 页面
- **THEN** 在标题下方、编辑区上方显示版本选择器一行
- **AND** 包含：当前版本标签（如「v2 · 后端方向」）、下拉箭头、保存按钮、新建版本按钮
- **AND** 使用 WarmButton 和 PaperCard 组件风格与页面一致

#### Scenario: 下拉菜单展开

- **WHEN** 用户点击版本标签区域
- **THEN** 下拉菜单展开，每个版本显示一行
- **AND** 每行包含：版本名称（可编辑）、创建日期、删除图标按钮
- **AND** 只有一个版本时不显示删除按钮
- **AND** 活跃版本行有选中标识（如对勾图标）

#### Scenario: 新建版本按钮

- **WHEN** 用户点击「+ 新建版本」
- **THEN** 弹出一个内联输入框（或小型模态框）
- **AND** 输入框有默认名称如「新版本」
- **AND** 确认后创建新版本并立即切换

#### Scenario: 内联重命名

- **WHEN** 用户在下拉菜单中双击版本名称
- **THEN** 名称变为可编辑的 input 框
- **AND** 按 Enter 或失焦时保存新名称

### Requirement: 编辑区与预览区适配

CV 页面的编辑区和预览区 SHALL 响应版本切换，展示当前活跃版本的内容。

#### Scenario: 版本切换后编辑区更新

- **WHEN** 用户切换到另一个版本
- **THEN** 编辑区（或预览区）的 5 个 section 内容替换为新版本的 sections
- **AND** 保存按钮回到灰色状态（新版本无未保存更改）

#### Scenario: 模板选择器不受版本切换影响

- **WHEN** 用户切换版本
- **THEN** 模板选择器（简洁经典 / 现代双栏 / 紧凑效率）保持当前选中状态不变
