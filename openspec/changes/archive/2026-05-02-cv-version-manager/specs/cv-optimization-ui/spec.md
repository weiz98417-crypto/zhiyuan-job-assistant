## MODIFIED Requirements

### Requirement: 简历基础信息

用户可以编辑和管理个人简历的基础内容，通过版本系统为不同岗位维护多份简历。

#### Scenario: 编辑简历内容

- **WHEN** 用户打开简历优化页面
- **THEN** 显示当前活跃版本的简历编辑界面（Summary、工作经历、项目、教育、技能）
- **AND** 支持 Markdown 编辑
- **AND** 编辑后「保存」按钮激活，用户需手动保存

#### Scenario: 多版本简历管理

- **WHEN** 用户为不同岗位创建多个简历版本
- **THEN** 每个版本独立维护 5 个 section 内容
- **AND** 通过版本选择器快速切换
- **AND** 每个版本可以设置自定义标签（如「后端方向」「AI产品方向」）
