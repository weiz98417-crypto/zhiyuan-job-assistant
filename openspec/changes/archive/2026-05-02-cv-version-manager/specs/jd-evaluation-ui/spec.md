## ADDED Requirements

### Requirement: 无 CV 数据时 Block B 展示

评估报告的「简历匹配」区块在用户未提供简历数据时 SHALL 展示明确提示，而非捏造评分。

#### Scenario: 无 CV 数据时展示占位内容

- **WHEN** 用户评估 JD 时未在简历优化页面填写简历内容
- **THEN** Block B 区域显示提示文字：「尚未提供简历数据，无法进行匹配分析」
- **AND** 包含一个指向简历优化页面的链接按钮：「完善简历 →」
- **AND** 不显示匹配度百分比或任何评分数字

#### Scenario: 有 CV 数据时正常展示

- **WHEN** 用户已填写简历内容并重新评估同一 JD
- **THEN** Block B 正常显示关键词覆盖、技能缺口等匹配分析
- **AND** 评估分数 `b` 基于 CV 内容真实计算
