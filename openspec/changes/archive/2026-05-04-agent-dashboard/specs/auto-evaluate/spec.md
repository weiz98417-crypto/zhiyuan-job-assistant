## ADDED Requirements

### Requirement: JD 自动评估

系统 SHALL 在用户粘贴 JD 内容后自动触发评估，无需手动点击"开始评估"按钮。

#### Scenario: 粘贴文本自动触发

- **WHEN** 用户在 evaluate 页面输入框粘贴 JD 文本（≥50 字符）
- **THEN** 2 秒防抖后自动调用评估 API
- **AND** 流式展示评估报告
- **AND** 输入框旁显示"正在评估..."状态指示

#### Scenario: 粘贴 URL 自动触发

- **WHEN** 用户在 evaluate 页面输入框粘贴 URL
- **THEN** 系统先抓取 URL 内容 → 自动触发评估
- **AND** 显示两步进度："正在获取 JD 内容..."→ "正在评估..."

#### Scenario: 手动触发保留

- **WHEN** 用户清空输入框后手动输入或编辑 JD 文本
- **THEN** 不自动触发（仅在粘贴时自动触发）
- **AND** 保留"开始评估"按钮供手动触发

#### Scenario: 内容过短不触发

- **WHEN** 用户粘贴的内容少于 50 字符
- **THEN** 不自动触发评估
- **AND** 输入框保持正常状态，等待用户继续输入
