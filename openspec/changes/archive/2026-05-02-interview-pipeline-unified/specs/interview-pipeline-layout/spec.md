## ADDED Requirements

### Requirement: 单页 Pipeline 布局

系统 SHALL 将面试准备页从三 Tab 架构改为单页四区 Pipeline 布局，按自然准备流程纵向排列。

#### Scenario: Pipeline 区域展示

- **WHEN** 用户打开面试准备页
- **THEN** 页面按顺序展示三个区域：配置区（顶部）、题目列表（中部）、已练列表（底部）
- **AND** 配置区默认展开，包含 JD 选择器、CV 状态、公司预设、生成按钮
- **AND** 已练列表默认折叠，可点击展开

#### Scenario: 练习面板替换题目列表

- **WHEN** 用户点击某道题目的 [练习] 按钮
- **THEN** 题目列表区域收起，替换为练习对话面板
- **AND** 练习面板顶部显示"← 返回题目列表"按钮和当前题目文本
- **AND** 配置区和已练列表保持可见但折叠

#### Scenario: 返回题目列表

- **WHEN** 用户在练习面板中点击"← 返回题目列表"
- **THEN** 练习面板收起，题目列表重新展开
- **AND** 如果本次练习产生了对话，已练列表刷新显示最新记录

### Requirement: Pipeline 进度可见

系统 SHALL 在题目卡片上展示练习状态，让用户感知整体进度。

#### Scenario: 题目练习状态标记

- **WHEN** 题目列表中有已练习的题目
- **THEN** 该题目卡片右上角显示绿色"已练习 ✓"标记
- **AND** 如果已评分，显示分数（如"4.2/5"）

#### Scenario: 进度统计

- **WHEN** 题目列表非空
- **THEN** 列表顶部显示进度文字（如"已练习 3/8 题"）
- **AND** 按分类统计：技术 1/3、行为 2/2、案例 0/2、文化 0/1
