# Proposal: d-dual-canvas-ui

## Problem Statement

界面层是两个无法测试的巨石（页面组件与聊天组件各约 2700 行），消息渲染分支、观察者分支与投影白名单三处手工对齐且已漂移；工具卡与审批卡的形态各自为政。视觉上界面原始且带着"AI 生成感"（emoji 图标、无个性的通用样式），与"求职伙伴"的产品气质不匹配；所有内容挤在一条聊天列里，报告与证据没有自己的舞台。信息架构此前已定本版不动。

## Solution

以双面画布布局整体换血界面层：左侧旅程栏（会话列表升级为带任务图标与状态的求职旅程轨）、中部对话面（暖白瓷、恒定窄列，只承载对话、审批卡与过程轨道）、右侧分析面（深炭、按需展开，报告/提案预览/岗位池在此打开，最大化即工作台全屏态）。聊天组件层采用 assistant-ui（外置存储运行时对接自研 Run 观察者 store，Thread/Composer/ToolUI/ApprovalCard），通用组件层采用 shadcn/ui，两者共享同一套纸鸢设计令牌（去黄化 claude 基准：暖白瓷纸 + 朱砂情感轴 + 深炭分析面 + 霞鹜文楷中文标题 + Noto Sans SC 正文），图标统一 Lucide 线性图标并执行"去 AI 味四禁"。消息编辑/重生成分支禁用。

## User Stories

1. As a 求职用户, I want 会话列表像"求职旅程"一样有阶段和状态, so that 我能回顾每一段求职进展。
2. As a 求职用户, I want 对话区安静克制、只在需要我决策时出现审批卡, so that 陪伴感不被信息轰炸破坏。
3. As a 求职用户, I want 报告和提案预览在旁边展开而不是把聊天冲垮, so that 我能边看证据边继续对话。
4. As a 求职用户, I want 审批卡有统一可信的形态（风险、后果、可回滚说明、批准/拒绝）, so that 敢于按下批准。
5. As a 求职用户, I want ⌘K 命令面板直达任意工作台/新任务, so that 不用在导航里找路。
6. As a 求职用户, I want 上岸时刻有庄重的庆祝态（排版与朱砂，不用表情符号）, so that 成功时刻有仪式感。
7. As a 求育用户, I want 界面图标风格统一细腻, so that 产品看起来专业可信。
8. As a 深度用户, I want 工作台（发现/报告库/简历）是分析面全屏态、与对话共享组件语言, so that 全产品体验一致。
9. As a 管理员, I want admin 后台色调与新设计对齐, so that 内外部观感统一。
10. As a 开发者, I want 聊天 UI 的通用问题（滚动/输入/可达性/键盘）由成熟库承担, so that 自研代码只剩领域卡片。
11. As a 开发者, I want 视觉令牌只有一份定义, so that 换肤和迭代不需要满仓找色值。

## Implementation Decisions

- 布局骨架：三栏（旅程栏 / 对话面 / 分析面）；分析面可关闭、可最大化（=工作台全屏态）；桌面优先，窄屏分析面以覆盖层呈现。信息架构（页面集合与导航关系）本版不变。
- 聊天组件层：assistant-ui，外置存储运行时（ExternalStoreRuntime 语义：消息源=服务端投影 store，运行中=乐观层），消息转换将对话项映射为线程消息；工具卡走 ToolUI 挂载领域卡片，审批卡采用 ApprovalCard 形态替换现有审批组件；不提供消息编辑/重生成回调（分支能力禁用，规避其分支史已知摩擦）。
- 通用组件层：shadcn/ui（copy-in）；⌘K 命令面板采用 cmdk 类方案；动效点缀按需取 Magic UI 级 copy-in 组件，不新增运行时依赖。
- 设计令牌：单一令牌文件（暖白瓷画布/软面/卡片面、墨色阶、朱砂主色与深浅、深炭分析面与边界、语义色含仅警示用的 amber），由去黄化的 claude 基准 DESIGN.md（awesome-design-md 合集）翻译而来，落库为仓库根 DESIGN.md 的更新与 Tailwind 令牌；字体：标题层霞鹜文楷、正文层 Noto Sans SC、数字 tabular。
- 图标：Lucide 统一线宽；执行"去 AI 味四禁"（emoji 作 UI 图标、紫色渐变、玻璃卡墙、Inter 字体）作为评审清单项。
- 上岸时刻（Offer 确认、评估高分）以排版与朱砂构建庆祝态。
- admin 后台：仅做 antd 主题令牌对齐，不重写。
- 旧聊天组件随切换删除，不留双路径、不加 feature flag（决策：能跑即直上，回滚靠 git 整体回退 0.10.8）。
- 页面组件巨石随本次换血大幅缩减：路由/创建/观察逻辑上移至 A/B/C 的模块，页面只保留组装。

## Testing Decisions

- 组件外部行为测试：给定投影消息/事件 → 期望渲染要点（审批卡按钮、交接横幅、委派轨道、报告卡），不测内部状态。
- 布局断言：三栏结构、分析面开合、⌘K 面板可达性（Playwright 冒烟——先例：verify-desktop-layout 类脚本）。
- 令牌一致性：单一令牌源生成的样式变量被组件引用（防散落硬编码色值的 lint 规则）。
- 视觉验收：以真实构建走查样张 v2 的场景清单（对话脸/分析面/上岸/令牌规范）。

## Out of Scope

- 信息架构重构（导航重排、页面合并）——下一版单独立项。
- admin 后台的组件重写。
- 视觉稿先行流程（以可运行构建 + 样张走查代替）。
- 消息编辑/重生成/分支史。

## Further Notes
