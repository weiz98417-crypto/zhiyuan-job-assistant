## 2. A-G 评分详解

### A 板块 — 岗位概览

提取 JD 的结构化信息：
- 检测到的 Archetype（6 类之一）
- 领域：AI产品/AI运营/AI解决方案/AI项目管理/AI咨询/AI增长
- 职能：产品规划/运营增长/售前方案/项目管理/战略咨询/市场营销
- 职级：初级/中级/高级/专家/总监
- 工作模式：远程/混合/坐班
- 团队规模（如有提及）
- 一句话 TL;DR

### B 板块 — 简历匹配

核心匹配逻辑——读取 `cv.md`，逐条映射 JD 要求：

| JD 要求 | CV 匹配项 | 匹配度 | 说明 |
|---------|----------|--------|------|
| 3年AI产品经验 | article-digest.md #3 | 强 | 做过AI客服机器人从0到1 |

**Gaps 分析**（每个缺口 4 层追问）：
1. 硬性要求还是锦上添花？
2. 能否用相邻经验证明？
3. 有没有作品集项目可覆盖？
4. 具体弥补方案

**按 Archetype 调整优先级**：
- AI产品经理 → 优先 PRD、产品规划、数据驱动决策
- AI运营 → 优先增长指标、AI工具应用、A/B测试
- AI解决方案 → 优先方案设计、客户沟通、技术广度
- AI项目经理 → 优先交付记录、跨团队协作、风险管理
- AI咨询顾问 → 优先行业洞察、方法论、变革推动
- AI增长/市场 → 优先增长指标、渠道经验、AI内容工具

### C 板块 — 职级与策略

中国语境下的职级对应：
- P6/P7/P8（阿里职级）≈ 中级/高级/专家
- T3/T4/T5（腾讯职级）

策略输出：
1. "卖senior不撒谎"方案——跨领域经验定位为优势
2. "如果被downlevel"方案——接受条件、review机制、晋升标准
3. 注意：不同公司职级体系差异大，不机械对应

### D 板块 — 薪酬与市场

**中国数据源**：
- 脉脉："<公司> <岗位> 薪资"
- 看准网：公司评价和薪资
- Boss直聘薪资查询：同类岗位薪资区间
- OfferShow（应届/初级岗位）
- 牛客网（技术相关岗位）

**评估维度**：
- 该公司在行业内的薪资竞争力（前25%/中等/偏低）
- 五险一金缴纳情况
- 加班情况（搜索"<公司> 加班"）
- 年终奖情况

**薪资计算**：
```
税前年薪 = 月薪 × N个月 + 年终奖
实际到手 ≈ 税前年薪 - 五险一金个人部分 - 个税
公积金入账 = 公司+个人缴存（按基数和比例计算）
```

### E 板块 — 定制化方案

简历前 5 项修改 + 作品集前 5 项修改，含原因和具体措辞建议。

中国语境下的简历格式：
- 中文简历 1 页原则（丰富经验可放宽到 2 页）
- 个人信息：姓名、邮箱、手机、期望城市
- 教育背景：学校名称+专业+学历

### F 板块 — 面试准备

STAR+R 故事映射（STAR + **Reflection 反思**）：

| JD要求 | STAR+R故事 | S | T | A | R | Reflection |
|--------|-----------|---|---|---|---|------------|

**反思列**：学到什么或下次怎么做——体现 seniority。

按 Archetype 框架化故事：
- AI产品经理 → 产品决策、trade-offs、用户洞察
- AI运营 → 增长策略、数据驱动、AI工具应用

### G 板块 — 职位合法性

不参与评分，独立定性评估。三个等级：
- **高可信度** — 多数信号正面
- **谨慎推进** — 混合信号
- **疑似虚假** — 多个虚假/无效指标

特殊情况处理：
- 国企/事业单位：时间线更长正常（放宽阈值）
- 持续招聘岗：不是虚假岗，是储备岗
- 高管/专家岗：合法持续数月开放
- 猎头联系：本身是正面信号

## 3. 评估输出

### 报告格式

```markdown
# 评估报告：{公司} — {岗位}

**日期：** {YYYY-MM-DD}
**Archetype：** {检测到的archetype}
**Score：** {X/5}
**Legitimacy：** {等级}
**URL：** {URL}

## 🛡️ 风险提示 (如检测到)
| 信号 | JD原文 | 权重 | 信号等级 | 说明 |

## A-G 板块内容

## 提取的关键词 (15-20个)
```

### 校验层

```bash
node scripts/validate-output.mjs --data '{
  "overall_score": 4.2,
  "date": "2026-05-09",
  "status": "Evaluated",
  "report_path": "reports/042-bytedance-2026-05-09.md"
}'
# Exit 0 → 校验通过 → db-write.mjs
# Exit 1 → 校验失败 → 重新生成
```

### 持久化

```bash
# 应用记录 → SQLite applications 表
node scripts/db-write.mjs --action upsertApp --data '{...}'

# 报告元数据 → SQLite reports 表
node scripts/db-write.mjs --action upsertReport --data '{...}'
```
