### 2. OCR 图片识别

**支持三种输入方式**：
- 粘贴 (Ctrl+V)：监听 `ClipboardEvent`，提取 `image/png` 或 `image/jpeg`
- 拖拽 (Drag & Drop)：`onDragOver`/`onDrop` 事件，提取 `File` 对象
- 文件选择：`<input type="file" accept="image/*">` 点击触发

**处理流程**：
```
图片 → FileReader.readAsDataURL() → Base64
  → 5MB/文件限制, 最多10张
  → 队列管理 (QueueItem: id/file/previewUrl/base64/status/retries)
  → 逐张OCR识别
  → 拼接文本 → 填入JD输入框
```

**状态管理**：
| 状态 | 含义 |
|------|------|
| `upload` | 等待上传 |
| `processing` | OCR 识别中 |
| `confirm` | 显示识别结果，等待确认 |

### 3. 流式评估

SSE (Server-Sent Events) 实时流式传输评估结果：
- 连接: `EventSource` 或 `fetch()` + ReadableStream
- 每个板块 (A-G) 完成后推送一个事件
- 前端实时渲染 ReportBlocks
- 支持中途断开重连

### 4. 评估结果展示

`ReportBlocks` 组件渲染 A-G 7 个板块：
- A: 职位概览表格
- B: 简历匹配表格 (JD要求→CV映射)
- C: 职级策略
- D: 薪资分析 (含数据来源)
- E: 定制化方案 (简历修改建议)
- F: 面试准备 (STAR+R 故事表格)
- G: 职位合法性评估

如果检测到风险信号，顶部显示 `🛡️ 风险提示` 表格。
