## 2. DATA_CONTRACT 分层

```
User Layer (NEVER auto-updated):
  用户数据、自定义、工作产出 — 更新永不修改
  ├── cv.md                      个人简历
  ├── config/profile.yml          身份、目标、薪资
  ├── modes/_profile.md           自定义 archetype 映射
  ├── article-digest.md           详细证明点
  ├── portals.yml                 搜索配置
  ├── data/applications.md        只读 legacy
  ├── data/pipeline.md            只读 legacy
  ├── reports/*.md                评估报告
  └── output/*.pdf                生成的简历

System Layer (safe to auto-update):
  系统逻辑、脚本、模板 — 随版本更新
  ├── modes/*.md                  模式文件
  ├── scripts/*.mjs               工具脚本
  ├── templates/*                 基础模板
  ├── CLAUDE.md                   Agent 指令
  └── VERSION                     版本号
```

**硬规则**：Agent 自定义必须写入 User Layer（`modes/_profile.md` 或 `config/profile.yml`），绝不写入 System Layer。

## 3. 写入路径

### 规范路径：db-write.mjs → SQLite

```bash
# 应用记录
node scripts/db-write.mjs --action upsertApp --data '{
  "num": 42, "date": "2026-05-09", "company": "Acme",
  "role": "AI PM", "score": 4.2, "status": "Evaluated",
  "pdf_generated": 0, "report_path": "reports/042-acme-2026-05-09.md",
  "notes": ""
}'
# → INSERT ... ON CONFLICT(company, role) DO UPDATE

# 报告元数据
node scripts/db-write.mjs --action upsertReport --data '{...}'
# → INSERT ... ON CONFLICT(report_num) DO UPDATE
```

### Fallback 路径：TSV（db-write.mjs 不可用时）

```bash
# 写入 batch/tracker-additions/042-acme.tsv
# 9 列 tab 分隔
042\t2026-05-09\tAcme\tAI PM\tEvaluated\t4.2/5\t❌\t[042](reports/...)\t备注
```

### 输入净化

`db-write.mjs` 对所有输入做净化：
- 控制字符过滤（`[\x00-\x08\x0b\x0c\x0e-\x1f]`）
- score 范围校验（1.0-5.0）
- date 格式校验（YYYY-MM-DD）
- company/role 不能为空
- SQLITE_BUSY 指数退避重试（3次, max 2s）

## 4. 并发与完整性

| 机制 | 实现 |
|------|------|
| WAL 模式 | `pragma journal_mode=WAL` — 读写并发安全 |
| 繁忙超时 | `pragma busy_timeout=5000` — 等 5 秒 |
| 重试 | `runWithRetry()` — 指数退避 100ms→400ms→2s |
| 去重 | `ON CONFLICT(company, role)` — SQLite 原生 upsert |
| 错误日志 | `data/db-write-errors.log` — 失败写入自动记录 |

## 5. 迁移策略

### 初始导入

`server-db.ts` 的 `migrateFromFiles()` 函数：
- 解析 `data/applications.md` → 逐行导入 `applications` 表
- 解析 `reports/*.md` → 提取元数据 → 导入 `reports` 表
- 已存在记录（同 company+role 或同 report_num）自动跳过

### 回滚

- SQLite 文件删除 → 重新运行 `migrateFromFiles()` 恢复
- 所有改动是增量文件 → `git revert` 即可
