### 状态系统: 以 templates/states.yml 为单一权威来源

状态筛选不硬编码标签。前端从 `templates/states.yml` 动态加载规范状态定义：

```yaml
# templates/states.yml (权威来源)
states:
  evaluated:  { label: "已评估", canonical: true }
  applied:    { label: "已投递", canonical: true }
  responded:  { label: "有回复", canonical: true }
  interview:  { label: "面试中", canonical: true }
  offer:      { label: "已获 Offer", canonical: true }
  skip:       { label: "跳过", canonical: true }
  rejected:   { label: "已拒绝", canonical: true }
  discarded:  { label: "已放弃", canonical: true }
```

前端通过 `/api/sessions` 或构建时预载读取 states.yml，生成筛选标签。新增状态无需改前端代码。

### 数据流

```
Agent 评估 JD → /api/agent/persist-eval → repository (当前 LAN: Postgres)
  → 前端 GET applications/reports API → 表格渲染
  → 用户手动更新状态 → PUT/PATCH API → repository
  → Agent tool: check_pipeline_health → 读 applications → 主动提醒
```

### 画像 Agent: profile-agent + mine_profile

新增 `profile-agent` 和 `mine_profile` tool，实现 Agent 被动的"用户画像深度挖掘"：

```
Agent tool: mine_profile
  → 读取 profiles + applications + reports
  → 分析投递模式（投了哪些方向、哪些被拒、哪些拿到面试）
  → 分析偏好演变（拒绝的岗位共性、accept 的 preference 记录）
  → 分析技能缺口（高频 JD 要求 vs 当前 skills 列表）
  → 输出画像洞察报告：
    "你过去 3 个月投递中 80% 是 AI 产品方向，
     但你的 skills 列表缺少 '大模型应用落地' 关键词。
     建议补充。另，你的 deal-breakers 应包含 '大小周'——
     你拒绝了 3 个有大小周的岗位。"
```

与 DeepSeek 分析不同，mine_profile 走 Agent 内部的 Claude/DeepSeek 推理链，结合全量历史数据。

## 面试准备页 (`/interview`)

| # | 功能 | 实现 |
|---|------|------|
| 1 | 公司选择 | 从 applications 表中读取 |
| 2 | AI 出题 | Agent tool: `prepare_interview_full` (生成面试题 + 公司情报) |
| 3 | 模拟面试 | Agent tool: `start_interview_session` → `/api/agent/coach/session` |
| 4 | 回答评分 | `/api/agent/coach/session` 内置评分逻辑 |
| 5 | STAR 故事库 | `/api/stories` CRUD 管理（读写 stories 表） |
| 6 | 公司情报 | 基于 Agent 评估报告的公司专属面试建议 |
| 7 | 面试会话管理 | `/api/sessions` — 会话创建/恢复/历史 |

### 模拟面试引擎 (NEW)

```
用户: "模拟面试：字节 AI PM"
  → Agent tool: start_interview_session(company, role)
    → 读取 JD 关键词 + story-bank
    → 创建 /api/agent/coach/session (会话 ID)
    → 出第 1 题（基于 JD 高频考点）
  → 用户回答
  → POST /api/agent/coach/session (提交回答)
    → 评分（1-5）+ 改进建议
    → 自动追加到 /api/stories（STAR 故事库）
    → 出第 2 题（根据前一轮表现动态调整难度）
  → ... 多轮 ...
  → Agent: "面试结束。总分 3.8/5。你的强项：技术深度。短板：STAR 故事结构。已为你补充 3 条新故事到故事库。"
```

### API 端点

| Endpoint | Method | 功能 |
|----------|--------|------|
| `/api/profile/dna` | GET | 获取画像 DNA（技能向量、经验图谱） |
| `/api/sessions` | GET | 获取用户会话列表（含面试历史） |
| `/api/sessions` | POST | 创建新会话 |
| `/api/sessions/{id}` | GET | 获取会话详情 + 消息历史 |
| `/api/agent/coach/session` | POST | 创建/恢复模拟面试会话 |
| `/api/agent/coach/session` | PUT | 提交回答，推进面试 |
| `/api/stories` | GET | 获取 STAR 故事库 |
| `/api/stories` | POST | 添加 STAR 故事 |
| `/api/stories/{id}` | PUT/DELETE | 编辑/删除 STAR 故事 |
