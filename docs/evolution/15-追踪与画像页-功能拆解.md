# 15 — 投递追踪 & 求职画像页功能拆解

## 投递追踪页 (`/tracker`)

| # | 功能 | 实现 | 数据源 |
|---|------|------|--------|
| 1 | 应用列表 | 表格视图 (公司/岗位/分数/状态/日期) | IndexedDB |
| 2 | 状态筛选 | 8个标签页 (ALL/EVALUATED/APPLIED/INTERVIEW...) | 前端 filter |
| 3 | 排序 | 分数/日期/公司/状态 4种模式 | 前端 sort |
| 4 | 状态更新 | 下拉选择 8 种规范状态 | `upsertApp()` → IndexedDB |
| 5 | 备注编辑 | 内联编辑备注字段 | IndexedDB |
| 6 | 报告查看 | 点击报告链接 → Markdown 渲染 | SQLite reports 表 |
| 7 | URL 打开 | 点击 URL → `window.open()` 浏览器打开 | applications 表 |
| 8 | PDF 下载 | 点击 PDF 图标 → 下载 | output/*.pdf |
| 9 | 批量操作 | 批量修改状态/删除 | IndexedDB |

### 状态筛选实现

使用 `STATUS_LABELS` 和 `STATUS_ORDER` (来自 `@/types`)：

```typescript
const tabs = [
  { key: "all", label: "全部", filter: () => true },
  { key: "evaluated", label: "已评估", filter: a => a.status === "evaluated" },
  { key: "applied", label: "已投递", filter: a => ["applied","responded","interview","offer"].includes(a.status) },
  { key: "interview", label: "面试中", filter: a => a.status === "interview" },
  { key: "top", label: "TOP ≥4", filter: a => a.score >= 4 },
  { key: "skip", label: "SKIP", filter: a => a.status === "skip" },
  { key: "rejected", label: "已拒绝", filter: a => a.status === "rejected" },
  { key: "discarded", label: "已放弃", filter: a => a.status === "discarded" },
];
```

每个标签显示计数 badge。

## 求职画像页 (`/profile`)

| # | 功能 | 实现 | 数据源 |
|---|------|------|--------|
| 1 | 基本信息 | 姓名/邮箱/手机/位置 | IndexedDB profiles 表 |
| 2 | 目标岗位 | 多项选择 + archetype 映射 | IndexedDB profiles.goals |
| 3 | 技能管理 | 技能列表 + 熟练度 (0-100) | IndexedDB profiles.skills |
| 4 | 薪资期望 | 最低/目标薪资区间 | IndexedDB profiles.goals |
| 5 | 意向公司 | 公司名称列表 | IndexedDB profiles.goals |
| 6 | 底线设置 | 996/外包/派遣 等 deal-breakers | IndexedDB profiles.goals |
| 7 | 画像分析 | `/api/profile/analyze` DeepSeek 分析 | DeepSeek API |

### 画像分析

`/api/profile/analyze` 调用 DeepSeek：
- 输入：完整 profile 数据 (skills + goals + deal-breakers)
- 输出：3-5 条画像优化建议
- 示例："你的技能集中在AI产品方向，建议补充数据分析能力的证明点"

### 意向公司管理

从 `portals.yml` 的 `tracked_companies` 加载预设公司，支持手动添加/删除。与首页"目标企业动态"联动——这里加了公司，首页就能看到相关新闻。
