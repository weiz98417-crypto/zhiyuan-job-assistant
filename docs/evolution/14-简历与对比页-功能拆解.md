# 14 — 简历管理 & Offer 对比页功能拆解

## CV 管理页 (`/cv`)

| # | 功能 | 实现 | 数据源 |
|---|------|------|--------|
| 1 | 简历查看 | Markdown 渲染 `cv.md` | 文件系统 (Read tool) |
| 2 | 简历编辑 | 富文本/Markdown 编辑器 | 前端状态 → Write 回写 |
| 3 | PDF 生成 | `generate-pdf.mjs` Playwright HTML→PDF | `templates/cv-template.html` |
| 4 | 简历模板 | `cv-template.html` (Space Grotesk + DM Sans 字体) | ATS 兼容格式 |
| 5 | 简历版本管理 | `ReferenceResume` (对比参考) | SQLite reference_resumes 表 |
| 6 | 简历搜索 | FTS5 全文搜索 | SQLite FTS |
| 7 | 锁定字段 | `useLockedFields` hook (简历部分字段锁定) | 前端状态 |

### PDF 生成流程

```
cv.md → modes/pdf.md (Claude Agent) → 填充 {{PLACEHOLDERS}}
  → /tmp/cv-{name}-{company}.html
  → node generate-pdf.mjs
  → output/cv-{name}-{company}-{date}.pdf
```

`cv-template.html` 使用 ATS 兼容格式：
- Space Grotesk (标题) + DM Sans (正文)
- A4 纸张，0.5in 边距
- 无图片、无表格、无复杂 CSS（ATS 解析器兼容）

### 锁定字段

`useLockedFields` hook 允许用户在编辑时锁定某些字段（如姓名、邮箱），防止误修改。状态存储在 IndexedDB 的 `lockedFields` 表中。

## Offer 对比页 (`/compare`)

| # | 功能 | 实现 | 数据源 |
|---|------|------|--------|
| 1 | Offer 选择 | 多选已获 Offer 的应用 | IndexedDB |
| 2 | 雷达图 | `RadarChart` 组件 (6 维可视化) | 前端计算 |
| 3 | 逐项对比表 | 薪资/福利/通勤/成长/稳定性/WLB | IndexedDB |
| 4 | 综合推荐 | 加权评分 → 排名 | 前端计算 |
| 5 | 薪资计算器 | 税前→税后转换 (含五险一金) | 前端公式 |

### 雷达图 6 维度

| 维度 | 数据来源 |
|------|---------|
| 薪资 | offer 中的薪资字段 |
| 福利 | 五险一金/公积金/年终 |
| 通勤 | 工作地点 + 用户位置 |
| 成长 | 岗位级别 + 公司规模 |
| 稳定性 | 公司融资阶段/上市状态 |
| WLB | 加班信号 + 工作模式 |

`RadarChart` 使用 SVG 绘制，支持 2-5 个 offer 同时对比。

### 薪资计算器

```
税前月薪 × N 个月 = 税前年薪
- 五险一金个人部分 (约 10.5% + 公积金 5-12%)
- 个税 (累进税率)
= 税后年薪
+ 公积金账户 (公司+个人缴存，可取)
= 实际收入
```
