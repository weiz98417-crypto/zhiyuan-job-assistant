## 1. 设计系统

### 创意北极星："一页翻开的手帐"

来自 `DESIGN.md` 的设计理念：
- 有机圆角体系（8px → 24px，随层级上升变圆）
- 温暖的琥珀色承担界面 30-50% 的视觉重量

### 编排流程

```
用户输入 → classifyIntent(正则) → AgentDefinition
    │
    ├── CareerDNA (IndexedDB / API 画像)
    ├── SessionContext (会话摘要 + 3 层记忆)
    ├── AgentKnowledge (特定领域知识)
    ├── ClaudeAgentActivity (Claude 最近活动 ← Agent 互通)
    └── AgentPreferences (学习到的用户偏好)
    │
    ▼
AgentPromptContext → buildSystemPrompt → agentLoop → SSE 流式响应
```

### 服务端 Agent 循环（`server-runner.ts`）

Phase 2 新增的服务端 ReAct Loop，运行在 `/api/agent/run` 内部：

- **直接调用 DeepSeek API**（API key 在服务端，不暴露客户端）
- **直接执行工具**（`registry.execute()`，不经 HTTP fetch 代理）
- **质量门控**：自动检测空结果、无关结果（如百度百科 TV 剧集条目）和乱码文本
- **forceTextOnly 机制**：工具永久错误后代码级拦截下一轮 tool_calls，LLM 只能输出文本
- **模型降级**：DeepSeek V4 Flash → Pro → GLM-4.6V FlashX → Qwen-Long 四级降级
- **上下文预算**：MAX_CONTEXT_TOKENS=64000，DEFAULT_TOOL_CTX_CAP=800
- **SSE 阶段指示**：emit `thinking/searching/executing/done` 阶段事件 → 前端 AgentStatusBar 渲染

客户端 loop（`client-runner.ts`）保留用于 `/api/agent/think` 路径，服务端 loop 用于 `/api/agent/run`。

## 5. 共享内存层（shared-memory.ts）

所有 Agent 的统一记忆层：

| 函数 | 数据源 | 内容 |
|------|--------|------|
| `getCareerDNASummary()` | IndexedDB / API | 技能、目标、薪资、底线 |
| `getSessionContext()` | 会话消息 + 3 层记忆系统 | 最近 10 条用户消息摘要 + 长会话摘要 + 跨会话语义记忆 |
| `getKnowledgeForAgent()` | 知识库 | 薪资基准、面试风格等 |
| `getClaudeAgentActivity()` | `/api/agent/claude-activity` → SQLite | Claude 最近 5 条评估 |
| `getAgentPreferences()` | `/api/agent/prefs` → SQLite | 学习到的用户偏好（含衰减） |

### 三层记忆系统（`src/lib/agent/memory/`）

详见 [08-Agent互通机制](./08-Agent互通机制.md)。简言之：

1. **Working Memory**（`working.ts`）：最近 10 轮对话，直接截断
2. **Episodic Memory**（`episodic.ts`）：15+ 轮后自动摘要早轮对话，存入 `session_memory` 表
3. **Semantic Memory**（`semantic.ts`）：跨会话事实提取，长期保持

由 `memory/coordinator.ts` 统一编排，替代原始的 `getSessionContext()`。
