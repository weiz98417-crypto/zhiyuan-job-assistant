## 1. 设计系统

### 创意北极星："一页翻开的手帐"

来自 `DESIGN.md` 的设计理念：
- 有机圆角体系（8px → 24px，随层级上升变圆）
- 温暖的琥珀色承担界面 30-50% 的视觉重量
- 拒绝一切"招聘App"刻板印象——没有表格堆砌、没有企业蓝

### CSS 变量（globals.css）

```css
:root {
  /* Primary — Warm Amber Glow: the committed voice */
  --color-primary: oklch(75% 0.12 75);
  --color-primary-hover: oklch(72% 0.13 75);

  /* Surface — Cream Paper baseline, never pure white */
  --color-bg: oklch(97% 0.005 85);
  --color-surface-raised: oklch(100% 0 0);

  /* Text — Warm Ink, never pure black */
  --color-text: oklch(25% 0.01 260);
  --color-muted: oklch(65% 0.005 85);

  /* Elevation — warm paper shadows, not dark box-shadows */
  --shadow-md: 0 2px 8px oklch(50% 0.01 85 / 0.06);

  /* Border Radius — organic, ascending with hierarchy */
  --radius-sm: 8px; --radius-md: 12px; --radius-lg: 16px;
  --radius-xl: 20px; --radius-2xl: 24px;

  /* Typography */
  --font-display: "LXGW WenKai", "KaiTi", serif;
  --font-body: "Noto Sans SC", "PingFang SC", sans-serif;
}
```

## 3. TypeScript Agent 系统

Next.js 前端内置 5 个 TypeScript Agent：

| Agent | ID | 意图匹配 | 功能 |
|-------|-----|---------|------|
| 面试教练 | `interview` | 面试/模拟/练习 | 出题、评分回答 |
| JD 评估 | `evaluate` | 评估/分析JD | 快速评估 |
| 求职画像 | `profile` | 定位/方向 | 职业探索 |
| 简历生成 | `resume` | 简历/CV | CV 生成 |
| 通用助手 | `general` | 兜底 | 一般对话 |

### 编排流程

```
用户输入 → classifyIntent(正则) → AgentDefinition
    │
    ├── CareerDNA (IndexedDB 画像)
    ├── SessionContext (会话摘要)
    ├── AgentKnowledge (特定领域知识)
    └── ClaudeAgentActivity (Claude最近活动 ← Agent互通)
    │
    ▼
AgentPromptContext → buildSystemPrompt → agentLoopClient → SSE 流式响应
```

## 5. 共享内存层 (shared-memory.ts)

所有 Agent 的统一记忆层：

| 函数 | 数据源 | 内容 |
|------|--------|------|
| `getCareerDNASummary()` | IndexedDB | 技能、目标、薪资、底线 |
| `getSessionContext()` | 会话消息 | 最近 10 条用户消息摘要 |
| `getKnowledgeForAgent()` | 知识库 | 薪资基准、面试风格等 |
| `getClaudeAgentActivity()` | `/api/agent/claude-activity` → SQLite | Claude 最近 5 条评估 |
