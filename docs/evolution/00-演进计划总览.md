# 筝筝纸鸢（ZhiYuan）演进计划总览

## 产品愿景

> 从"海投焦虑"到"精准掌控" — 让每个求职者都有一个 AI 求职伙伴帮你评估、避坑、决策。

## 项目现状

筝筝纸鸢是一个面向中国市场的 AI 求职助手，已完成从 CLI 工具到全栈 Web 应用的完整演进。

项目当前处在“多用户 + Agent 治理 + 长期记忆”的阶段：局域网运行态使用 PostgreSQL/pgvector，SQLite 保留为本地 fallback、迁移源和归档读取路径；Agent Chat 已具备图片入口、任务契约、工具治理、读回校验、运行台账和复盘治理能力。

### 核心运行能力

- **图片入口重做**：Agent Chat 上传图片后先走 `/api/agent/image-intake`，识别 JD、Offer、简历、聊天截图、无关图片或冲突场景，再进入对应 Agent 或要求澄清。
- **任务契约与工具治理**：每个高风险任务都有成功条件，工具声明副作用、允许任务、Agent 白名单、读回要求和中文展示名；不满足契约时不能宣称完成。
- **读回校验**：JD/Offer 报告、简历修改、优秀简历保存、文件导出等写入类工具必须有读回证据，否则进入失败/待处理路径。
- **Agent Run 台账**：Postgres 启用后记录 run、step、phase、tool、contract、verifier 和错误，前端 Agent Chat 展示活动 run 状态，管理员可在运行台查看。
- **复盘治理与 Eval 候选**：终态 run 会触发确定性复盘，沉淀路由错、图片识别失败、缺读回、上下文漂移等 eval 候选；接受/提升不会自动改代码，仍需开发者显式纳入测试。
- **PostgreSQL/pgvector 基础**：`DB_DRIVER=postgres` + `DATABASE_URL` 后启用 repository 数据路径、向量记忆表、运行台账和复盘治理。
- **优秀简历长期记忆**：用户要求保存优秀简历时，需要先确认岗位方向（如 AI 产品经理、AI 运营、AI 售前）；私有材料仅本人可检索，团队共享材料走管理员治理。
- **上下文压缩可见化**：长会话触发摘要时，Agent Chat 会进入 `compressing_context` 状态，摘要写入会话记忆后再继续对话。
