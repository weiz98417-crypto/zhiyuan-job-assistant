# 筝筝纸鸢（ZhiYuan）演进计划总览

## 产品愿景

> 从"海投焦虑"到"精准掌控" — 让每个求职者都有一个 AI 求职伙伴帮你评估、避坑、决策。

## 项目现状（2026-05-22）

筝筝纸鸢是一个面向中国市场的 AI 求职助手，已完成从 CLI 工具到全栈 Web 应用的完整演进。

### Phase 4 (NEW): 企业招聘官网职位扫描系统

从 32 家北上广深杭互联网/科技公司的招聘官网自动抓取职位信息：
- **双通道架构**: API (Greenhouse/Lever, 零成本) + Playwright 浏览器 (Moka/北森/自定义)
- **LLM 通用提取**: Claude Haiku 结构化提取任意招聘页面 (~$0.02/公司)
- **5 个 ATS 适配器**: Greenhouse, Lever, Moka (12家公司), 北森 (5家), Custom/LLM (15家)
- **后台 Worker**: `scan-worker.mjs` 轮询 + CAS 取任务 + 崩溃恢复 + 优雅关闭
- **SQLite 数据层**: `scan_queue` + `scan_jobs` 表, URL 去重, title_filter 过滤
- **/discover 页面**: 实时扫描进度 + 职位卡片 + 侧边评估面板 + 历史记录
- **新增文件**: lib/scan/ (8个), scripts/scan-worker.mjs, server.mjs, 6个 API 端点
