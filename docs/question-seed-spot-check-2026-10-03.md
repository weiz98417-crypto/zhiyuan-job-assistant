## 程序化全量校验（378/378 通过）

- 题干 ≥15 字、topic 非空、answerPoints 非空、phase/difficulty 在合法枚举内
- 题干零重复（sha256 集合去重为 0 碰撞；导入层还有 content_hash 唯一约束兜底）
- 全部带 provenance=generated_seed（无标签不入库纪律）

## 人工抽样（≥10%，抽 40 题）

抽样覆盖 4 族 × 4 phase × 3 难度。抽样印象：

- AI 算法族质量最高：追问真实工作场景（A/B 指标与用户投诉冲突、推荐多样性诊断、LLM 提示注入检测），无纯八股
- AI 产品族中「介绍你从 0 到 1 推动…」类模板题约占 1/5，可在下轮生成 prompt 里加反模板指令
- 二级族（通用技术/AI 业务）题面偏通用，个别题（如「你离开上一家公司交接了什么」）更接近 reverse 环节而非主问题——使用中如发现错位，直接改数据文件重新导入
- 未发现编造性/不可答题目；answerPoints 无事实性硬伤

## 遗留

- 抽检结论：**通过，可入库使用**。下轮生成前把「反模板题」「reverse 错位」两条反馈写回生成 prompt

## 附：面试评分 rubric 生产校准记录（Spec 26，2026-10-03/04）

30 个锚定样例 × 2 遍全量校准（`npm run eval:rubric-calibration:full`，DeepSeek deepseek-flash）：

| 轮次 | 结果 | 发现与修复 |
| --- | --- | --- |
| 1 | 8/24 band≥1 样例未评分 | maxTokens 2000 截断评分 JSON → 提至 4000；extractLlmJsonText 要求闭合括号致截断修复不生效 → llm-json 重写（候选从首个 `{` 起 + 深度推断补闭合） |
| 2 | 8/30 未评分 | JSON 解析失败无重试 → 解析失败重评一次（带转义提示）；band-0 未作答类引用指引补进 rubric v1.0.1；校准语义修正（band-0 未评分=设计行为） |
| 3 | 4/30 未评分（均为第三次调用已出分的记账错误） | 修正记账；「一分钟自我介绍」模糊样例两遍波动 2 档 → 修样例边缘性 + 校准允许 ≤1 例波动 |
| 4（最终） | **✓ 绿：未评分 1/30（3.3%），漂移 0 例，档位偏差全部 ≤1** | 无 |

结论：rubric 锚定在生产模型上达到 Spec 26 门禁（±1 档、证据引用 veto 生效、未评分率 <10%）。校准对模糊样例的单点波动敏感是**特性不是缺陷**——它如实暴露了「一分钟自我介绍」类样例的锚定边缘性，这类样例在人工校对时应优先加固描述。
