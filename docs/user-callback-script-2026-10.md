# 用户回访提纲(10 人,A2 视觉反测的需求验证)

用途:UPGRADE-PLAN-2026-10B 为「简历视觉层反测」登记的触发条件。逐人 10-15 分钟,可以微信语音/面聊;2026-10-06 grilling Q7 定为与机器回路并行,不阻塞回路建设。回访结论写回本文末尾「回访记录」,作为模板美化是否立项的依据。

## 开场(30 秒)

「我们在改进简历功能,想问你几个具体的问题,没有对错,照实说就行。」

## 十个问题

1. 你现在投简历,用的是 Boss 直聘在线简历、附件 PDF,还是两者都用?哪个用得多?
2. (若用 Boss 在线简历)你在手机上预览过自己的简历吗?看完觉得怎么样?
3. 你觉得自己的简历「好看」吗?1-10 分打几分?扣分扣在哪?
4. 你有没有因为「排版/样式」原因重做过简历?当时是什么刺激了你?
5. 你会对比别人的简历样式吗?比如同事/网上模板?看过之后动过手吗?
6. 你觉得 HR 看你简历会看多久?你希望 TA 最先注意到什么?
7. (给 Ta 看两版同样的内容、不同排版的简历截图,A 简洁黑白 / B 信息密度高的彩色)你更愿意投出哪版?为什么?
8. 如果 AI 提示「你这版简历 HR 三秒扫视可能抓不到重点」,你希望它:只提示问题 / 直接给一版改好的 / 给几个模板让你挑?
9. 你为简历样式花过钱吗(模板/代做/设计)?花过多少?以后愿意为「自动把简历变好看」付多少?
10. 你上一份工作投了多少份简历、约到几个面试?你觉得回复率低的主要原因是什么(如果想过)?

## 记录要点(每人都记)

- 投递主渠道与预览习惯(手机/电脑)
- 对样式的自我评分与扣分点(原话)
- 问题 7 的选择与理由(A/B 偏好是核心信号)
- 问题 8 的形态偏好(提示 vs 代改 vs 模板)
- 付费意愿(有/无/金额)

## 判读标准(回访完填)

- ≥7 人主渠道是 Boss 在线简历 → 视觉问题成立性高
- 问题 7 偏好显著一致(≥8 人同侧)→ 模板方向有共识
- ≥3 人有付费意愿/历史 → 美化立项的商务依据
- 回复率归因集中在「样式」的人数 ≥4 → 优先级升;集中在「内容/匹配」→ 维持美化后置
