# Spec 40 账号与旧缓存恢复增量

基线：`4ffdd91`。范围：W01 / ISS-048 的旧缓存隔离和可信恢复。原 67 项问题保持开放，本文件不替代 392 项外部验收。

设置页新增隔离目录，只展示类别、位置和捕获时间，不展示无 owner 原始正文。旧 IndexedDB 原样保留，不参与目录内容读取。其他账号、未同步资料、坏数据和缺证据资料保留 `needs_review`，不能用勾选“属于我”绕过核验。

旧 CV 恢复分两步：预览计算排序稳定的 SHA-256，服务端用当前有效账号、当前 CV 版本和正文核验，返回有效期 10 分钟的签名归属凭据；恢复时重新验签、owner、云端同步 ID、内容 hash 和旧隔离快照，使用服务端独立读回正文写入当前 owner 缓存。不同草稿或晚到换号请求拒绝；服务端 CV 不写入。已恢复的同内容不重复覆盖。

恢复凭据持久化到当前 owner 的缓存并独立读回；目标或凭据读回失败回滚本次新增。撤销只删除本次新增且 hash 未变的缓存，后续新草稿受保护；旧隔离原文一直保留。该恢复切片支持与云端完全匹配的旧 CV，其余未同步 storage / 旧数据库资料仍需更完整的人工核验与恢复流程，不宣称全部旧数据迁移完成。

新增测试先红后绿覆盖隔离目录不泄露、当前 owner 签名凭据、其他 owner / 伪造 / 云端新版本拒绝、撤销与读回失败回滚、迟到恢复、后续新草稿保护、会话撤销和跨语言环境 hash。已有 UNIT/SIM 和 SQLite API 结果不等于真实浏览器或 PostgreSQL；独立浏览器结果在完成后记录。
