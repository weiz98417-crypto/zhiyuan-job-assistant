# 纸鸢 Agent — 0.13.3

日期：2026-10-14（北京时间）。本次按用户最新指令发布已验证的分批修复，不宣告 Spec 40 全部完成。

## 改进与修复

- 对话恢复保留用户补充、图片用途、禁止写入约束与输入身份；专家交接保留任务目标、来源与权限，研究委派需明确授权。
- 会话加载与 URL 切换完成后才允许发送，防止创建无关联 Run；加载失败展示错误并支持重试。
- 面试区分控制指令与答案，核验补充材料和换绑；评分证据必须来自当前回答，非法评分保留未评分。
- 职业定位展示来源，避免把学习计划、否定或示例升级成用户经历；确认保存后独立读回。
- 浏览器资料和异步响应按账号隔离；旧无归属缓存隔离保留，可证明归属的旧简历支持恢复与撤销。
- 敏感记忆需要用途确认；读取检查清除抑制、来源归属和分区；页面提供真实加载、错误与重试状态。
- 自动采集核验已接收的真实用户输入，禁止保存、仅当前对话使用及虚构资料不进入画像信号，后续轮次继承限制。
- Offer 缺失条件保持未知，显式零值保留；确定现金、非保证奖金和估算假设分开。
- 导入明确新增、重复与非法数据，错误写入回滚，不以默认值掩盖无效输入。
- 发布备份使用一致快照；正常清除与恢复重放分别核验，恢复回执绑定实际备份与每条清除请求，不要求改写正常清除的历史标记。

## 数据与发布约束

Offer 迁移只移除未知字段的默认值与非空约束，不重写历史条件。旧缓存原件和历史真实用户记录保留，修复前需核实来源与批准范围。

生产切换前必须完成一致备份、隔离恢复读回、严格记忆门、Runtime preflight、Worker 排空及回滚准备；未满足时保留旧生产版本。

67 项问题、完整 392 项验收、全层擦除/恢复矩阵及剩余业务页面修复继续按既有方案推进。实际发布结果记录在对应部署回执中。
