# 模式：scan — 国内招聘平台扫描（中文版）

当用户要求搜索新职位时，从国内主流招聘平台获取匹配的岗位信息。

## 支持的平台

| 平台 | 特点 | 扫描方式 |
|------|------|---------|
| BOSS直聘 | 直聊模式，岗位更新快 | Web搜索 + 关键词过滤 |
| 拉勾 | 互联网行业为主 | Web搜索 |
| 猎聘 | 中高端岗位 | Web搜索 |
| 脉脉 | 内推和公司动态 | Web搜索 |
| 51job | 传统行业覆盖广 | Web搜索 |
| 智联招聘 | 综合性平台 | Web搜索 |

## 搜索参数

从 `config/profile.yml` 读取：

### 岗位关键词
- 目标角色（target_roles.primary）
- 相关角色（target_roles.archetypes）

### 城市筛选
- 首选城市（location.preferred_cities）
- 是否接受远程（location.open_to_relocation）

### 薪资过滤
- 最低月薪（compensation.minimum_k）K
- 目标区间（compensation.target_range.min_k - max_k）K

### 排除关键词
- 外包/驻场/派遣
- 996/大小周（如果用户不接受）
- 无公积金/最低基数
- 特定行业/公司

## 扫描流程

### 1. 构建搜索
每个岗位关键词 × 每个城市 = 搜索组合

### 2. 结果筛选
- 标题匹配度（positive/negative 关键词过滤）
- 薪资在可接受范围
- 公司规模/融资阶段符合偏好
- 排除已投递的公司（从 `data/applications.md` 读取）

### 3. 去重
- 跨平台去重（同一公司在不同平台的同一岗位）
- 与历史扫描记录去重（`data/scan-history.tsv`）

### 4. 排序
- 匹配度优先（archetype fit）
- 薪资符合度
- 公司评分

## 输出格式

```
## 扫描结果 — {日期}

共发现 {N} 个新职位（已过滤 {M} 个）

### 高匹配（≥4.0预估）
| # | 公司 | 岗位 | 薪资 | 平台 | 匹配度 |
|---|------|------|------|------|--------|

### 可考虑（3.0-3.9预估）
| # | 公司 | 岗位 | 薪资 | 平台 | 匹配度 |
|---|------|------|------|------|--------|

### 新增公司
- {公司名}：{简介} — {为什么值得关注}
```

## 注意事项

- 国内平台反爬较严格，单次扫描不宜超过 20 个搜索组合
- 扫描结果写入 `data/pipeline.md`，由用户决定哪些进入评估
- BOSS直聘需要模拟手机端 User-Agent
- 不要对同一平台连续高频请求
