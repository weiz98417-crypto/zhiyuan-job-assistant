# 模式：followup — 跟进节奏管理（中文版）

当用户需要跟进投递或面试进度时，根据中国求职市场规范给出建议。

## 跟进时间表

### 投递后跟进
| 场景 | 建议时间 | 方式 |
|------|---------|------|
| BOSS直聘已读未回 | 24小时后 | 发送简短追问 |
| BOSS直聘未读 | 48小时后 | 检查在线状态，考虑撤回重发 |
| 拉勾/猎聘投递 | 3-5个工作日 | 查看进度或邮件询问 |
| 内推投递 | 5-7天 | 通过内推人礼貌询问 |

### 面试后跟进
| 场景 | 建议时间 | 方式 |
|------|---------|------|
| 一轮面试后 | 3个工作日 | 邮件/微信感谢信 + 简短追问 |
| 终面后 | 5个工作日 | 礼貌询问进展 |
| 口头Offer后 | 2-3天 | 跟进书面Offer进展 |
| 超时未回复 | 7天 | 最后一次跟进，之后归档 |

### 谈薪阶段跟进
| 场景 | 建议 |
|------|------|
| 提交薪资期望后 | 2-3天后跟进 |
| 对方压价后 | 准备好竞品Offer或市场数据再回复 |
| 多Offer并行谈判 | 注意时间窗口，不要让任何一家等超过5天 |

## 跟进话术模板

### BOSS直聘已读不回追问
```
"您好，看到您已读了我的消息。我对这个岗位很感兴趣，我的背景与要求比较匹配：[简述匹配点]。方便的话可以进一步沟通，谢谢！"
```

### 面试后感谢信
```
"{面试官称呼}您好，感谢您今天的时间。通过沟通我对{公司}和{岗位}有了更深入的了解，也更加确认自己的兴趣和匹配度。期待后续进展，如有需要补充的信息请随时联系。"
```

### 追问面试结果
```
"{HR称呼}您好，打扰一下。上次面试已经过去几天了，想了解一下后续的安排和进展。如有需要我补充的材料请告知，谢谢！"
```

### 礼貌拒绝
```
"{HR称呼}您好，感谢贵司的认可和Offer。经过慎重考虑，我决定接受另一个更符合我职业规划方向的机会。非常感谢您的耐心沟通，希望以后有机会再合作。"
```

## 特别提醒

- **不要频繁追问**：中国HR通常比较忙，频繁追问会产生负面印象
- **尊重工作时间**：工作日 10:00-12:00 或 14:00-17:00 发送消息
- **避开午休和下班后**：12:00-14:00 和 18:00 后不发送
- **周末不打扰**：除非是紧急Offer确认
- **BOSS直聘特殊性**：消息已读不回很常见，不要过度解读
- **春节/国庆前后**：招聘节奏会明显减慢，耐心等待
