# 模式：pdf — 中文简历 PDF 生成

## Pipeline 完整流程

1. 读取 `cv.md` 作为内容源
2. 如果上下文中没有 JD，向用户索取（文字或URL）
3. 从 JD 提取 15-20 个关键词
4. 检测 JD 语言 → 输出语言（中文 JD → 中文简历）
5. 检测目标地点 → A4 纸张（中国标准）
6. 检测岗位 archetype → 调整叙事框架（见 `modes/zh/_profile.md`）
7. 重写"专业摘要"（Professional Summary）：注入 JD 关键词 + 职业转型叙事桥接
8. 选择与 JD 最相关的 top 3-4 个项目经历
9. 按 JD 相关度重排工作经历中的要点
10. 构建 JD 要求的能力矩阵（6-8 个关键词/短语）
11. 将关键词自然注入现有成就（绝不编造）
12. 从模板 + 定制内容生成完整 HTML
13. 从 `config/profile.yml` 读取姓名 → 标准化为 kebab-case（如"张三"→"san-zhang"）
14. 写入 HTML 到 `/tmp/cv-{candidate}-{company}.html`
15. 执行：`node generate-pdf.mjs /tmp/cv-{candidate}-{company}.html output/cv-{candidate}-{company}-{YYYY-MM-DD}.pdf --format=a4`
16. 报告：PDF路径、页数、关键词覆盖率

## 中文简历排版规则（ATS兼容）

- **单栏布局**（不要侧边栏、不要并行列）
- **标题使用标准命名**："专业能力"、"工作经历"、"教育背景"、"项目经历"、"技能证书"
- **不要在图片/SVG中放文字**
- **不要在页面顶部/底部（header/footer）放关键信息**（ATS解析器忽略）
- **UTF-8编码，文本可选中**（非图片化）
- **不要嵌套表格**
- **JD关键词分布**：摘要区（前5个）+ 每个岗位第一条要点 + 技能区

## 中文字体与排版

**字体方案：**
- **标题字体：** Noto Sans SC Bold（或思源黑体 700）
- **正文字体：** Noto Sans SC Regular（或思源黑体 400）
- **数字/英文混排：** 使用系统中的等宽字体或保持Noto Sans SC
- **备选字体：** 苹方 (macOS) / 微软雅黑 (Windows)

> **注意：** `templates/cv-template.html` 使用 Space Grotesk + DM Sans 自托管字体。生成中文PDF时，需在HTML中声明中文字体 fallback：`font-family: 'Space Grotesk', 'Noto Sans SC', 'PingFang SC', 'Microsoft YaHei', sans-serif;`

**字号与间距（中文简历）：**
- 标题：13px / letter-spacing 0.05em
- 正文：11px / line-height 1.6（中文需要比英文更大的行高）
- 段落间距：6px

**纸张格式：**
- 中国标准：**A4**（210mm × 297mm）
- 命令：`node generate-pdf.mjs input.html output.pdf --format=a4`

## 中文简历内容规范

### 个人信息区（可选）
- 姓名（居中，24px bold）
- 邮箱 · 手机 · 期望城市（一行，用 · 分隔）
- 照片：除非JD明确要求，否则不加（降低歧视风险）
- 不要写：性别、年龄、民族、籍贯、婚姻状况、身份证号

### 专业摘要（2-3行）
- 第一句：身份定位（你的角色 + 核心能力）
- 第二句：最具代表性的成就（含指标）
- 第三句：对目标岗位的价值主张

### 工作经历
- 时间倒序
- 每个岗位 3-5 个要点
- 每个要点 = 动作动词 + 具体成果 + 量化指标
- 中文动作动词参考：主导、推动、搭建、优化、设计、落地

### 项目经历
- 选择与JD最相关的 3-4 个
- 每个项目 2-3 个要点
- 包含：项目目标、你的角色、技术/方法、成果

### 教育背景
- 学校名称 + 专业 + 学历 + 时间
- GPA 如突出可加（>3.5/4.0 或 >85/100）

### 技能
- 按类别分组：产品工具、数据分析、AI能力、语言等
- 不要写"精通"——写成使用场景
- 例如：「LangChain + RAG（搭建过处理日均5000+查询的客服系统）」

### 中文简历常见问题

**Q: 要不要放照片？**
A: 除非JD明确要求（如部分国企、传统企业），否则不放。科技/AI行业尤其不需要。

**Q: 要不要写"期望薪资"？**
A: 不要在简历上写。面试中口头沟通。

**Q: 要不要写"政治面貌"？**
A: 根据岗位要求。非国企/事业单位不建议写。

**Q: 简历几页？**
A: 5年以下经验尽量1页；5-10年可以2页；10年以上视情况。

## ATS 兼容性（中文版）

- `generate-pdf.mjs` 自动处理 Unicode 归一化（全角→半角数字等）
- 但避免在内容中混用全角/半角，保持统一
- 中文标点（，。、；：）在中文上下文中没问题
- 英文专业术语保持元样，不要翻译（RAG、Agent、Pipeline）
