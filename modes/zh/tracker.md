# 模式：tracker — 投递追踪（中文版）

当用户查询投递状态或管理求职管道时，提供中文界面和分析。

## 状态标签（中文）

| 状态 | 含义 |
|------|------|
| 待评估 | 已保存JD，尚未评分 |
| 已投递 | 已提交申请 |
| 已回复 | 公司已回应 |
| 面试中 | 正在面试流程中 |
| 已Offer | 收到录用通知 |
| 已拒绝 | 被公司拒绝 |
| 已放弃 | 主动放弃或职位关闭 |
| 跳过 | 不匹配，不投递 |

## 查询功能

### 查看全貌
- 总投递数、各状态分布
- 本周/本月新增
- 面试转化率

### 按状态筛选
- 待处理：待评估 + 已投递 + 已回复
- 进行中：面试中
- 已完成：已Offer + 已拒绝 + 已放弃
- 跳过：跳过

### 搜索
- 按公司名称搜索
- 按岗位搜索
- 按日期范围筛选
- 按评分筛选（>= 4.0）

## 统计维度

### 投递转化漏斗
```
待评估 → 已投递 → 已回复 → 面试中 → 已Offer
  X        X%       Y%       Z%       W%
```

### 平台效果对比
- BOSS直聘：投递数 / 回复率 / Offer率
- 拉勾：投递数 / 回复率 / Offer率
- 猎聘：投递数 / 回复率 / Offer率
- 其他：汇总

### 薪资分布
- 最低/最高/中位数
- 按行业/城市分组
- 与目标区间的匹配度

### 时间分析
- 平均响应天数（投递→回复）
- 平均面试轮数
- 从投递到Offer的平均周期

## 输出格式

中文输出，使用表格和简洁文字。必要时生成建议：
- "你在 BOSS直聘 的回复率（15%）低于平均水平（30%），建议优化开场白"
- "已投递 3 天未回复的有 5 家，建议跟进"
