# 模式：deep — 公司深度调研（中文版）

当用户要求调研某家中国公司时，从国内数据源获取信息并输出结构化评估报告。

## 数据源优先级

1. **企查查** — 工商信息、股权结构、司法风险
2. **天眼查** — 公司背景、对外投资、行政处罚
3. **脉脉** — 员工评价、薪资爆料、面试经验
4. **IT桔子** — 融资历史、行业赛道
5. **36氪/虎嗅** — 媒体报道、行业分析
6. **看准网** — 公司评分、薪资数据
7. **公司官网/招聘页** — 团队规模、办公地址

## 评估维度

### 1. 基本信息
- 公司全称、注册地、成立时间
- 注册资本、实缴资本
- 法定代表人、股权结构
- 社保缴纳人数（工商年报）

### 2. 融资与规模
- 融资阶段（天使轮/A轮/B轮/C轮/D轮/已上市/未融资）
- 融资金额和投资方
- 团队规模（参保人数 + 脉脉员工数）
- 办公地址和分支机构

### 3. 业务分析
- 主营产品和业务线
- 目标市场和用户规模
- 竞争对手和市场地位
- 商业模式和收入来源

### 4. 风险评估

#### 劳动合同风险
- 外包/本部/劳务派遣 识别
- 签订主体是否与招聘公司一致
- 换签/转签历史

#### 经营风险
- 司法案件和被执行人信息
- 行政处罚和经营异常
- 欠税和破产相关记录
- 社保欠缴风险

#### 行业政策风险
- 政策监管变化
- 行业整顿和合规要求
- 数据安全和隐私合规

### 5. 口碑与文化
- 脉脉员工评价汇总
- 加班文化（996/大小周/弹性）
- 福利待遇（是否全额缴纳五险一金）
- 离职率和员工满意度
- 晋升机制和培训体系

## 输出格式

```
## {公司名称} 调研报告

### 基本信息
| 项目 | 内容 |
|------|------|
| 全称 | ... |
| 成立 | ... |
| 融资阶段 | ... |

### 融资历史
| 时间 | 轮次 | 金额 | 投资方 |
|------|------|------|--------|

### 风险评估
- **劳动合同**: ...
- **经营风险**: ...
- **政策风险**: ...

### 员工评价摘要
...

### 总体建议
[是否推荐投递，需注意的风险点]
```
